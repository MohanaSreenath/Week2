# Overview
Week 2 is focused on mastering the pillars of object-oriented programming in Java. You will learn how to define and use classes and objects, implement constructors, understand important Java keywords, design robust systems using OOP principles, and apply inheritance and encapsulation to build maintainable and scalable Java applications.

# Topics Covered
Day 1: Java Classes and Objects

Defining classes and creating objects

Understanding class members: fields (attributes) and methods (behaviors)

Real-world modeling with classes (e.g., Area, Book, Employee, Inventory, Mobile)

Day 2: Constructors

Purpose and types of constructors (default and parameterized)

Constructor overloading

Initializing object state

Practical examples (e.g., Book, Car, Circle, Hotel, Library, Person)

Day 3: Java Keywords

Key Java keywords in OOP: this, static, final, super

Their usage and impact on class design and behavior

Example implementations (e.g., Bank, Emp, Hospital, Product, Student)

Day 4: OOP Design Principles

Association, aggregation, and composition

Designing relationships between classes (e.g., BankAssociation, CompanyComposition, LibraryAggregation, UniversityManagement)

Real-world system modeling using OOP principles

Day 5: Inheritance

Concept and benefits of inheritance

Creating class hierarchies and using extends

Method overriding and polymorphism

Example domains (e.g., Animal, Bank, Education, Library, School, Vehicle)

Day 6: Encapsulation

Data hiding and access control (private, public, protected)

Getters and setters

Designing robust classes (e.g., Bank, Employee, Food, Hospital, Library, Ride, Vehicle)

# Prerequisites
Completion of Week 1 (Java basics)

Java Development Kit (JDK) installed

Familiarity with a code editor or IDE (VS Code, IntelliJ IDEA)

# How to Use This Repository
The Week2 folder is organized into daily subfolders, each corresponding to a major OOP concept.

Each day's folder contains multiple example Java programs, typically at different difficulty levels (Level1, Level2).

Explore, run, and modify the code samples to reinforce your understanding.

Try extending the examples or building your own classes and relationships to deepen your grasp of OOP.
